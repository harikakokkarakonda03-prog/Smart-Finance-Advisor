# Smart Finance Advisor

Smart Finance Advisor is a personal finance expense tracker built using Java Servlets and MySQL.

## Features
- Add expenses
- Store expenses in MySQL database
- View expense list
- Visualize spending using charts

## Technologies Used
- Java
- Servlets
- Apache Tomcat
- MySQL
- HTML
- JavaScript
- Chart.js

## How to Run

1. Install Apache Tomcat
2. Setup MySQL database
3. Deploy the project inside Tomcat webapps folder
4. Start Tomcat server
5. Open in browser
